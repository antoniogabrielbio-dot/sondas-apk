🤖 Instalar App Nativo Android

O aplicativo Sondas 2.0 roda de forma nativa no seu celular, sem travamentos de navegador, mantendo o mapa e todas as sondas salvos 100% offline para uso no campo.

⚡ Baixar Sondas-2.0.apk (Arquivo APK Direto) 📦 Baixar Sondas-2.0.zip (Pasta Compactada ZIP) 🏠 Baixar via Rede Local Wi-Fi do PC
ℹ️ Dica rápida para instalar no celular:
  1. Após o download, toque na notificação "Sondas-2.0.apk concluído" ou abra os Downloads do Chrome.
  2. Clique em Instalar (se pedir para permitir fontes desconhecidas, marque Permitir).
  3. Se seu celular abrir como pasta compactada: clique nos 3 pontinhos do arquivo ➔ Abrir com ➔ Instalador de Pacotes.
